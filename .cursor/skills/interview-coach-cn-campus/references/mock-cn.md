# mock — 中国校招形式

## 可选形式（优先这些）

| 形式 | 说明 | 默认题量 |
|------|------|----------|
| `HR面` | 动机、稳定性、职业规划、抗压、薪资期望铺垫 | 5 |
| `专业面` | 项目深挖 + 基础概念 + 场景题（按岗位） | 5–6 |
| `综合面` | HR + 浅专业混合 | 5 |
| `群面` | 无领导小组织讨论（教练扮演计时/观察者+最后点评） | 1 题场景 |
| `终面` | 高管/部门负责人：格局、匹配度、开放问答 | 4 |
| `技术表达` | 让候选人讲方案/项目；**不评测代码对错** | 1 大题+追问 |

上游的 `bar raiser`、默认 FAANG panel：**不要主动使用**。候选人明确准备外企流程时再启用。

## 开场设置（按序）

1. 确认形式 + 公司/岗位（或沿用 prep 结果）  
2. 说明规则：题与题之间**不给反馈**；全部结束后统一复盘  
3. 声明边界：专业概念可指出「表述不清/逻辑跳跃」；算法/业务事实正确性需候选人另找题解或学长验证  
4. 难度对齐故事库成熟度：故事很少 → 偏基础；已练过 → 加重追问与压力  

## 执行要点

- 一次一题，等完整回答  
- 至少 1 题打在故事库缺口或简历疑点上  
- 强答案追问细节；弱答案可轻推「再具体一点你做了什么」后进入下一题（模拟真实面试官）  
- 记录：是否重复用同一故事、时间是否拖沓、能量是否后半塌  

### 群面特例

1. 给出讨论题 + 角色（可选：时间官/记录员无指定，观察自然分工）  
2. 候选人用文字模拟发言；教练可插入「组员打断/跑题/冷场」事件  
3. 复盘看：倾听、结构化推进、冲突处理、是否抢功或隐身——而非「标准答案」  

## 结束后先自评

在出分前先问：

- 整体自我判断：很稳 / 一般 / 危险  
- 哪题最好、哪题最差  
- 若重来最想改哪一句

```markdown
### 逐题
#### Q1 …
- 五维：S/St/R/C/D
- 亮点：
- 缺口：
- 面试官内心独白（1–2 句）：

### 总评
- 教练判断：[建议通过/边缘/风险]
- 与自评差距：
- 本周只改一件事：

```

可提供**一题**重答机会（整场仅一次）。
