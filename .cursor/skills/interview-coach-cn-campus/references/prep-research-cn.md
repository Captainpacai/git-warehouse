# prep / research — 中国校招版

## research [公司]（轻量）

目标：快速判断「值不值得深准备」，不是写长报告。

### 信息源优先级（诚实标注置信度）

1. 公司校招官网 / 官方公众号通知（高）  
2. 宣讲会 PPT、学长学姐/内推口述（中，注明来源）  
3. 尼客/看准/脉脉等议论（低，只作风险提示）  
4. 教练「常识」：必须标「一般知识/未核实」  

**禁止**：捏造「某公司必考题清单」或「必过话术」。

### 输出

```markdown
## 公司速览：[名称]
- 业务一句话：
- 校招节奏（若可知）：提前批/秋招/补录
- 常见流程：网申 → 笔试? → 专业/HR → …
- 岗位匹配初判：[较匹配/可冲/偏难] + 原因
- 置信度与缺口：还需要候选人补充什么
```

## prep [公司]（场次准备）

在 research 基础上，产出「上场清单」。

### 必问候选人（一次一项）

1. 哪一轮？（笔试后面试 / 专业一面 / HR / 终面 / 不清楚）  
2. 线上面还是现场？多久？  
3. 是否已有笔试/面试回忆或面经链接？（有则优先用，无则标低置信）  

### 准备包内容

1. **本轮考察假设**（标置信度）  
2. **故事映射**：从故事库挑 3–5 个，标「强匹配 / 可凑合 / 缺口」  
3. **可能疑虑**：学历、跨专业、实习短、成绩、稳定性… + 一句话应对方向  
4. **想问面试官的 3 个好问题**（岗位真实、团队、成长；避免纯福利堆砌除非 HR 轮）  
5. **当天 3×3**：3 个必讲故事要点 × 3 个易忘数据/关键词  

### 行业微调

| 行业 | prep 加重 |
|------|-----------|
| 互联网 | 项目深挖、业务理解、技术表达结构 |
| 国企/央企 | 动机稳定性、岗位匹配、规矩意识、实事求是 |
| 金融 | 合规与敏感、抗压、数字严谨、为什么选金融 |
| 外企 | 可混用英文自我介绍；文化仍按该公司国内校招习惯 |

**建议下一步**：故事缺口多 → `stories`；临近面试 → `mock [对应形式]`。
