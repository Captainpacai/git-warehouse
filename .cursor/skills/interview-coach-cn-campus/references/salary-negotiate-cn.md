# salary / negotiate — 中国校招版

## 硬原则

1. **不编造薪资数字**。只指导候选人去查：校招薪资帖、师兄师姐、offer 对比、官方/招聘口头带宽。  
2. **不提供法律意见**（三方、违约、劳动争议只给「常见做法 + 建议向老师/律师/就业指导中心确认」）。  
3. 校招谈薪空间通常**小于**社招；重点放在：期望表达、对比 offer、签字费/补贴、报到时间、户口/档案等「可谈项」。

## salary（早期：网申 / HR 问期望）

### 国内常见时间线

1. 网申「期望薪资」  
2. HR 面「你的期望」  
3. offer 前口头对口径  
4. 正式 offer → 转 `negotiate`  

### 话术策略（按阶段）

- **能晚说就晚说**：先了解城市、职级、是否包含实习/补贴。  
- **给区间不给死数**：区间下界 = 可接受最低；上界 = 有依据的冲刺。  
- **锚点来源**：同城同岗位同学 offer、往年校招包、公司已透露带宽——并在对话里用「根据我了解到的市场情况」而非「某网站写着」。  
- **应届生忌讳**：脱口「随便」「你看着给」——显得无准备；也忌漫天要价无依据。  

### 总包拆解（国内校招常用）

| 项 | 说明 |
|----|------|
| 月薪/年薪 base | 是否按 12/13/14–16 薪 |
| 签字费 / 年终 | 是否有、是否税前、发放条件 |
| 住房/交通/餐补 | 现金或实物 |
| 股票/期权 | 仅部分互联网；讲清归属与风险，勿当现金 |
| 户口/档案/落户支持 | 部分城市与国企关键点 |
| 三方与违约 | 报到时间、违约金、是否允许延毕 |

### 输出

```markdown
## 期望薪资准备
- 目标城市/岗位：
- 候选人自研区间：[低–高]（来源与置信度）
- 建议对外口径（30 秒版）：
- 被追问「当前/以往」时的应对：
- 不要说的话：
```

## negotiate（拿到 offer 后）

### 可谈清单（按公司类型勾选）

- base / 档位  
- 签字费、年终、补休假  
- 租房补贴、交通  
- 报到日期、户口/档案  
- 部门/方向（有时比多 1k 更重要）  
- 多 offer 对比话术（客观、不威胁、留体面）  

### 流程

1. 让候选人贴 offer 关键要素（可打码公司名）  
2. 列出「必须谈 / 想谈 / 可放弃」  
3. 给 1 版书面回复草稿 + 1 版电话口述稿  
4. 预设对方说「薪资结构统一不能改」时的 Plan B（转签字费、补贴、延期、方向）  

### 输出

```markdown
## Offer 谈判简报
- 现状摘要：
- 优先争取（最多 2 项）：
- 可让步：
- 沟通稿：
- 风险与需人工确认项：
```
