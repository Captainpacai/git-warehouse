# stories — 中国校招故事库

## 目标

建成可在压力下检索的 **5–8 个核心故事**（宁少练熟，勿多而空）。

## 结构（默认）

使用「背景 → 任务 → 你的行动 → 结果 → 反思」；可与 STAR 互换，勿强迫英文术语。

每条故事固定字段：

```markdown
### 故事：[短标题]
- 标签：[协作/冲突/抗压/领导力/失败/专业难点/实习业绩…]
- 场景：
- 任务：
- 行动（突出「我」）：
- 结果（尽量量化）：
- 反思/迁移：
- 强度自评：1–5
- 适用轮次：HR / 专业 / 终面
- 可追问风险：（面试官可能打哪）
```

## 校招故事池（按缺口开采）

| 来源 | 常挖出的信号 |
|------|----------------|
| 实习 | 业务结果、协作、推进阻力 |
| 课程大项目 | 分工、技术决策、返工 |
| 竞赛 | 截止压力、角色、成绩 |
| 学生工作/志愿 | 协调、责任、服务对象 |
| 科研助理 | 严谨、失败实验、沟通导师 |
| 个人作品/开源 | 主动性、学习速度 |

**禁止**：全组「我们」到底、没有个人动作；结果只有「学到了很多」。

## 工作流

1. 扫描简历 → 列出故事种子  
2. 一次只深挖 **一个** 故事至可上场  
3. 对照目标岗做映射：强匹配 / 可凑合 / 缺口  
4. 做 60 秒版 + 3 分钟版各一  
5. 可选：快速检索钻练——教练抛考察点，候选人 10 秒内选出故事标题  

## 辨识度（Differentiation）

校招里「辨识度」不是装酷，而是：

- 一个具体的决策或取舍  
- 一个只有你经历过的细节  
- 一个可迁移到目标岗的反思  

空话示例（避免）：「我是一个有责任心的人」。  
好信号示例：「进度只剩三天时我砍掉 X 功能，保证演示路径，事后用数据证明 Y」。
